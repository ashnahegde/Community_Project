GRAM SEVA — REFINED LOCAL STORAGE VERSION

15 complete files: 5 HTML, 5 CSS, 5 JavaScript.

FEATURES
- Refined responsive design for mobile, tablet and desktop.
- English and Kannada translations across the main user flows.
- Language selection remembered between pages.
- Citizen guidelines, complaint form, illustrated category cards.
- Optional photo attachment (maximum 2 MB).
- Automatic complaint reference and citizen tracking.
- Officials demo login, dashboard, filters, status updates and remarks.

RUN
1. Extract ZIP and open folder in VS Code.
2. Open index.html with Live Server.
3. Citizen: submit a test complaint and save the GP- reference.
4. Officials login: username official / password GP1234.
5. Update status and return to citizen portal to track it.

LIMITATIONS
Local Storage works only in the same browser profile/device. This is not a shared online database. Demo login is not secure authentication. Photo storage uses browser storage and may hit browser limits. Supabase/PostgreSQL is not connected in this version. Google Fonts need internet; fallback fonts are included.
